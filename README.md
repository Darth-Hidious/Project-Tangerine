# Robotic living zen garden

A desk-scale Japanese garden (moss, a running stream, stones, lanterns and a raked sand
bed) with a robot arm built into it that rakes the sand.

Status: design stage. Nothing physical has been built yet.

- `zen-garden/` is the in-silico twin (Python): a pattern generator, a rake-aware path
  planner with collision checks, and a heightfield sand simulation. It was started for a
  gantry over a gravel tray; the arm-in-the-garden design replaces the gantry next.
